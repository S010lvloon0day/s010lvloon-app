Политика конфиденциальности

Последнее обновление: апрель 2026 г.

1. Общие положения

Настоящая политика описывает, какие данные собирает сервис S010lvloon VPN при использовании Telegram-бота и мини-приложения, как они используются и защищаются.

2. Какие данные мы собираем

Мы собираем только минимально необходимые данные для работы сервиса:

  • Telegram ID и имя пользователя — передаются Telegram при запуске бота, используются для идентификации аккаунта и доставки ключей доступа.
  • Факт и дата оплаты, выбранный тариф — сохраняются для выдачи и продления подписки.

3. Что мы НЕ собираем

  • IP-адреса пользователей
  • Данные о трафике, посещаемых сайтах или активности в интернете
  • Данные об устройстве, браузере или операционной системе
  • Паспортные данные, номера телефонов, адреса электронной почты

Сервис работает по принципу Zero Logs — сетевой трафик не логируется и не анализируется.

4. Как используются данные

Собранные данные используются исключительно для:

  • Выдачи и управления ключами доступа к VPN
  • Обработки платежей и подтверждения оплаты
  • Отправки уведомлений об истечении подписки
  • Технической поддержки по запросу пользователя

5. Передача данных третьим лицам

Мы не продаём и не передаём персональные данные третьим лицам, за исключением:

  • Платёжный сервис CryptoBot — для обработки оплаты (только сумма и идентификатор заказа).
  • Telegram — как платформа, через которую работает бот (в соответствии с их политикой конфиденциальности).

6. Хранение и удаление данных

Данные хранятся на защищённом сервере в Европе. По запросу пользователя все его данные могут быть удалены — для этого напишите в поддержку: @S010lvloon_VPN_bot.

7. Контакты

По вопросам, связанным с обработкой персональных данных, обращайтесь: @S010lvloon_VPN_bot
